🖥️ Onsite Server — Command Cheat Sheet

Open this page on the Mini PC / standby, click Copy, paste into PowerShell (right-click the Start button → Terminal / PowerShell).

1 — Update code (do this to get the latest fixes)

Pulls latest backend + staff portal from GitHub, installs deps, runs migrations, pre-warms the sponsor-logo cache for offline badge printing, restarts the API. Run on the PRIMARY and the STANDBY.

powershell -NoProfile -ExecutionPolicy Bypass -File C:\rodeo\rodeo-fresh\scripts\onsite\update-code.ps1
⚠️ Restarts the RodeoAPI service — terminals see a few seconds of errors. Avoid mid-event unless it's an urgent fix.

2 — Pre-warm the sponsor logo cache only

Downloads every sponsor logo to local disk so badges print with logos when the grounds have no internet. Safe any time; skips what's already cached.

node C:\rodeo\rodeo-fresh\scripts\onsite\cache-logos.js

3 — Check the API is healthy

Invoke-RestMethod http://localhost:3000/health

4 — Restart the API service

Restart-Service RodeoAPI

If it won't start, check the service log:

nssm status RodeoAPI

5 — Update fails with "Not possible to fast-forward"

The repo on this machine has drifted from GitHub (usually a leftover from provisioning or the standby sync). This safely parks any local state on a backup branch — nothing is deleted — then matches GitHub exactly. Run it, then run command #1 again.

git -C C:\rodeo\rodeo-fresh branch "backup-$(Get-Date -Format yyyyMMddHHmm)"; git -C C:\rodeo\rodeo-fresh stash; git -C C:\rodeo\rodeo-fresh fetch origin; git -C C:\rodeo\rodeo-fresh reset --hard origin/main

Same thing for the staff portal folder if it ever gets stuck:

git -C C:\rodeo\holmdale-staff-portal branch "backup-$(Get-Date -Format yyyyMMddHHmm)"; git -C C:\rodeo\holmdale-staff-portal stash; git -C C:\rodeo\holmdale-staff-portal fetch origin; git -C C:\rodeo\holmdale-staff-portal reset --hard origin/main
